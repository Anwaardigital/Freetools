PDF Tools FAQs

How does the PDF Merger work?

Upload two or more PDF files, arrange them in the order you want, and merge them into a single PDF. Everything happens in your browser — your files are never uploaded to any server.

Can I merge password-protected PDFs?

No. Encrypted or password-protected PDFs cannot be processed by the merger. Remove the password protection first, then merge.

How do I split a PDF into separate pages?

Open the PDF Splitter, select your file, and enter the page numbers or page ranges you want. The tool extracts those pages into a new PDF file.

How much smaller will the PDF Compressor make my file?

It depends on the file. The compressor rebuilds the PDF's internal object streams, which works well on text and vector-based PDFs. Scanned PDFs made of page images may shrink very little. Results vary from file to file.

Why does PDF to Text return nothing from my scanned PDF?

The tool extracts selectable text from the PDF. Scanned pages are just images of text, so there is nothing to extract — the tool does not include OCR (optical character recognition).

Which image formats can I turn into a PDF?

The Images to PDF tool works with JPG and PNG images, which are embedded directly into the document. For WebP or BMP images, convert them to JPG or PNG first with the Image Converter.

Is there a file size or page limit for the PDF tools?

There is no fixed limit — everything runs locally in your browser, so the practical limit is your device's memory. Very large files may be slow on phones or older computers.

Are my PDF files uploaded anywhere?

No. All PDF processing happens entirely in your browser using JavaScript libraries. Your files never leave your device.

Will merging or splitting change my PDF's quality?

No. Pages are combined or extracted as-is without re-rendering, so text, images and layout stay exactly the same.

Image Tools FAQs

How does the Image Compressor reduce file size?

It re-encodes your image at an adjustable quality level. Lowering the quality setting produces a smaller file. You can choose JPG or WebP output.

Should I choose JPG or WebP output?

WebP usually produces smaller files at similar visual quality, while JPG works everywhere including older software. If compatibility matters most, pick JPG; if smallest size matters, try WebP.

Does the Background Remover work on any photo?

No — it removes white or light-colored backgrounds, which works best for logos and product photos on plain backgrounds. It is not an AI subject cutout, so it cannot cleanly remove complex backgrounds from portraits.

Can I resize an image to exact pixel dimensions?

Yes. The Image Resizer lets you set exact width and height in pixels, with an optional aspect-ratio lock so the image does not get stretched.

Which formats can the Image Converter handle?

It converts between PNG, JPG, WebP and BMP formats.

Will resizing or converting reduce image quality?

Enlarging an image can make it look soft, and converting to JPG is lossy, so some detail is discarded. Always keep a copy of your original file before converting.

What does the Favicon Generator create?

It generates small favicon-sized images from your uploaded picture, ready to use as a website icon.

Are my images uploaded to a server?

No. All image processing happens locally in your browser — your photos never leave your device.

Can I crop or rotate images too?

Yes. There are dedicated tools for cropping to a selected area and rotating or flipping images.

Text Tools FAQs

How does the Word Counter count words?

It splits your text on whitespace to count words, and also reports characters (with and without spaces), sentences, paragraphs and estimated reading time.

Which case formats does the Case Converter support?

UPPERCASE, lowercase, Title Case, Sentence case and aLtErNaTiNg (alternating case), among others. Paste your text, pick a format, and copy the result.

What is Base64 encoding used for?

Base64 converts text or binary data into plain ASCII characters so it can be safely included in URLs, emails, HTML or data URIs. The tool both encodes and decodes.

Is Base64 encoding secure?

No. Base64 is an encoding, not encryption — anyone can decode it instantly. Never use it to hide passwords or sensitive information.

What is Lorem Ipsum for?

It is placeholder text used by designers and developers to fill layouts before the final copy is ready. The generator produces as many paragraphs as you need.

What does the JSON Formatter do?

It formats (beautifies) JSON so it is easy to read, and validates it — if your JSON has a syntax error, the tool tells you.

Do the text tools work offline?

Yes. Once the page has loaded, all text tools run entirely in your browser with no internet connection needed.

Is text I paste into these tools sent anywhere?

No. Everything you type or paste is processed locally in your browser and never transmitted to any server.

Can I decode Base64 back into readable text?

Yes — paste the Base64 string into the decoder and it converts it back to the original text.

Security Tools FAQs

Are the generated passwords truly random?

Yes. The Password Generator uses your browser's cryptographically secure random number generator. Passwords are created locally and never sent anywhere.

What is a SHA-256 hash?

A fixed-length digital fingerprint of any text. Even a tiny change in the input produces a completely different hash. It is commonly used to verify that data has not been altered.

Can a SHA-256 hash be reversed?

No. Hashing is one-way by design — you cannot recover the original text from its hash.

How accurate is the IP Lookup?

It queries a public geolocation API and returns the approximate city, region, country, ISP and timezone for an IP address or domain. Accuracy is approximate — usually city-level at best, and VPNs, mobile networks or corporate networks can make it wrong.

Does a "Safe" result from the Phishing URL Checker guarantee a site is legitimate?

No. The checker runs client-side heuristics — suspicious top-level domains, IP-address hosts, URL shorteners and similar warning signs. It is a first-pass check only. When in doubt, never enter passwords or payment details.

Why can't the Security Headers Checker scan some websites?

Some sites block cross-origin header checks from browsers for security reasons. For those sites, the tool cannot read the headers — you can also try a dedicated scanner like securityheaders.com.

What are security headers?

HTTP response headers such as Content-Security-Policy and HSTS that protect a website against common attacks. The checker reports which recommended headers a site sends and which are missing.

Does using IP Lookup expose my own IP address?

Like visiting any website, your request goes through the public geolocation API the tool queries. The tool itself does not store or log your lookups.

Should I rely on these tools alone to stay safe online?

No — they are helpful checks, not complete protection. Also use unique passwords, turn on two-factor authentication, keep your software updated, and stay cautious with links and attachments.

Color Tools FAQs

How does the Color Picker work?

Pick any color visually and instantly get its HEX and RGB values, ready to copy into your design or code.

How do I convert HEX to RGB?

Paste a HEX color code into the converter and it shows the equivalent RGB values — and converts RGB back to HEX too.

What is the Contrast Checker for?

It calculates the contrast ratio between a text color and a background color, so you can check whether text is readable and accessible.

What contrast ratio should I aim for?

Higher ratios mean more readable text. The widely used WCAG accessibility guideline recommends at least 4.5:1 for normal body text.

What does the Gradient Generator create?

It builds smooth color gradients from the colors you choose and gives you the ready-to-use CSS code to paste into your website.

What are random color palettes useful for?

Design inspiration. The generator produces sets of colors that work well together for websites, graphics or branding ideas.

Can I copy the color codes?

Yes — HEX and RGB values can be copied to your clipboard with one click.

Do the color tools need an internet connection?

No. Once loaded, every color tool runs fully in your browser.

Will a picked color look the same on every screen?

The color values are exact, but screens differ in calibration and brightness, so the same code can look slightly different from device to device.

Developer Tools FAQs

What do the CSS and JS minifiers do?

They remove whitespace, line breaks and comments from your code to shrink file size, which helps pages load faster. Paste your code, minify, and copy the result.

Will minifying break my code?

Minifiers only strip unnecessary characters — valid code keeps working exactly the same. Still, always test the minified output and keep a copy of your original.

What is a UUID?

A Universally Unique Identifier — a 128-bit random ID commonly used as database keys, session IDs or unique filenames. The generator creates version 4 (random) UUIDs.

Are generated UUIDs guaranteed to be unique?

For practical purposes, yes. Random version-4 UUIDs have such an enormous number of possible values that accidental collisions are effectively impossible — but they are random, not cryptographically guaranteed.

What does the Timestamp Converter do?

It converts Unix timestamps (seconds since 1 January 1970) into human-readable dates and times, and converts dates back into timestamps.

What is URL encoding?

It converts special characters in URLs into %XX format so links stay valid — for example, a space becomes %20. The tool encodes and decodes URLs.

How does the Link Shortener work?

It sends your long URL to the is.gd API, which returns a short link. This is the one tool on the site that contacts an external service — every other tool runs fully in your browser.

Are shortened links permanent?

is.gd links are intended to last, but they live on is.gd's service, not on this site — so their long-term availability is up to is.gd.

Is my code sent anywhere when I use the developer tools?

No — except the Link Shortener, which must send the URL to is.gd to create the short link. Minifiers, encoders, the UUID and timestamp tools all run locally in your browser.
