🛡️ Security Headers Checker

Check a website's HTTP security headers — HSTS, Content-Security-Policy, X-Frame-Options and more — and learn what each one means. Free, unlimited.

How to use

  1. Enter a website URL (e.g. example.com).
  2. Click "Check Headers" — we fetch the response headers for you.
  3. Green means the header is present, red means it is missing.

FAQ

Is it really free?

Yes — every tool on this site is 100% free with no limits, no signup and no watermarks.

Why are some sites not checkable?

A few sites block cross-origin header checks. For a deeper scan, try securityheaders.com as well.
