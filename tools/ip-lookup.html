🌐 IP Lookup

Look up any IP address or domain — city, region, country, ISP and timezone. Free, unlimited — the lookup uses a public geolocation API.

How to use

  1. Enter an IP address (e.g. 8.8.8.8) or a domain (e.g. example.com).
  2. Click "Look Up" — or press "My IP" to detect your own address.
  3. Read the location and network details below.

FAQ

Is it really free?

Yes — every tool on this site is 100% free with no limits, no signup and no watermarks.

Is the location exact?

No. IP geolocation shows the approximate location of your internet provider's server — usually correct to the city, sometimes only the region.
