FAQ

Is it really free?

Is my data private?

Absolutely. All processing happens locally in your browser. Your files are never uploaded to any server.

What CSS code does the tool generate?

A standard declaration like background: linear-gradient(135deg, #667eea 0%, #764ba2 100%). The syntax is pure modern CSS — no vendor prefixes needed — and it also works as a background-image value you can layer with other backgrounds.

Can I use more than two colors?

Yes. Add extra color stops to build multi-color gradients — sunsets, ocean depths, or rainbow effects. Each stop gets its own color and position percentage, giving you full control over the blend.

What is the difference between linear and radial gradients?

Linear gradients blend colors along a straight line at an angle you choose (0° = bottom to top, 90° = left to right). Radial gradients blend outward from a center point in a circle or ellipse — ideal for glows, vignettes, and spotlight effects.

Will the gradient look the same in every browser?

Yes. The standard gradient syntax is supported identically by Chrome, Firefox, Safari, and Edge. Colors may vary slightly between screens due to display calibration, but the CSS itself renders consistently.

A quick color-theory primer

Gradients work best with colors that share a relationship. Analogous colors (neighbors on the color wheel, like blue to purple) blend seamlessly and feel calm. Complementary colors (opposites, like orange to blue) create vibrant energy but can turn muddy in the middle — add a midpoint stop to control the transition. For text overlays, keep gradients subtle and dark enough that white text stays readable.

Where gradients shine

Hero sections: a full-width gradient background instantly elevates a landing page. Buttons and CTAs: gradient buttons draw the eye without shouting. Image overlays: a dark gradient fading upward makes white headline text legible over any photo. Cards and dividers: thin gradient rules and borders add polish. Dark mode: subtle gradients prevent flat dark surfaces from looking lifeless.

Pro techniques

Use hard stops (two stops at the same percentage) for crisp striped or duotone effects instead of smooth blends. Layer a semi-transparent gradient over a background image for depth. Animate gradients subtly with background-position shifts for living, breathing interfaces — but keep motion gentle to respect users with vestibular sensitivities. And always check contrast ratios: decorative gradients are fine, but text sitting on a gradient must still meet accessibility standards.

Performance and best practices

CSS gradients are resolution-independent and typically lighter than background images — a big win for page speed. Prefer CSS over gradient PNGs wherever possible. When you need the exact same gradient in multiple places, store it as a CSS custom property (--brand-gradient) so a future rebrand means editing one line.
