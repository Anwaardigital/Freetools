PDF Merger

Combine multiple PDF files into one document and arrange them in any order you choose. Useful for joining contracts, reports or scanned pages into a single file. Free, unlimited, private — works entirely in your browser.

How to use

  1. Click the drop zone and select two or more PDFs in the order you want them merged — or drag and drop them in order. A numbered list shows each file with its size.
  2. Check the numbered list carefully: file 1 becomes the first pages of the merged document, file 2 the next pages, and so on.
  3. Click "Merge PDFs" — all pages are combined into one document, in that order, entirely in your browser.
  4. Your merged file downloads automatically as merged.pdf, and the tool shows the total size of the new document.

FAQ

Is it really free?

Yes — every tool on this site is 100% free with no limits, no signup and no watermarks.

Is my data private?

Absolutely. All processing happens locally in your browser. Your files are never uploaded to any server.

How do I control the order of the merged PDF?

The merged document follows the order in which you select the files, shown as a numbered list (1, 2, 3…). The first file you select becomes the first pages of the output, the second file the next pages, and so on. Select the files in the order you want them to appear — and double-check the list before clicking Merge PDFs.

Is there a limit on how many PDFs I can merge?

No — there is no artificial limit on the number of files or total size. The only practical constraint is your device's memory, since all processing happens in your browser. Very large merges (hundreds of pages) may take a while on older phones or computers, so be patient while the progress message shows.

Will merging change my documents' quality or layout?

No. Pages are copied exactly as they are — fonts, images, formatting, hyperlinks and bookmarks are preserved, even when the source PDFs have different page sizes or orientations. Merging rearranges nothing; it simply concatenates the pages into one file.

Can I merge PDFs with different page sizes or orientations?

Yes. Each page keeps its original size and orientation in the merged file. A mix of A4 and letter pages, or portrait and landscape pages, all work fine — nothing is scaled, rotated or cropped.

How PDF Merging Works (and When to Use It)

Merging a PDF sounds simple — stick one document after another — but doing it cleanly takes real engineering. Each PDF carries its own fonts, image resources, page sizes and internal object tables, and a naive "glue the bytes together" approach would produce a broken file. This tool uses the open-source pdf-lib engine to properly load every source PDF, copy each page's content and resources into a brand-new document, and rebuild a valid internal structure. The pages land in the new file pixel-identical to the originals, with nothing re-rendered or degraded.

Because everything runs in your browser, your documents never travel to a server. The PDF engine itself is fetched from a CDN once (an internet connection is needed for that first load); after that, even large merges work fully offline. Your original files are never modified — merging always creates a new file, so you can experiment freely.

Best use cases

Merging is the go-to move whenever one complete document matters more than several scattered files. Classic examples: combining a contract with its signature pages and annexures into a single file for signing; collecting monthly invoices or receipts into one PDF for expense reports and tax filing; joining chapters of an e-book or thesis that were exported separately; and assembling scanned pages — a multi-page document scanned one page at a time — into one tidy file. It's also handy for application packets: CV, cover letter, certificates and portfolio in a single upload-friendly document.

Tips for the best results

The single most important thing is selection order: the tool merges files in exactly the order you pick them, so select (or drag) them deliberately — cover page first, appendices last. If a source PDF is bloated, shrink it first with the PDF Compressor; merging pre-compressed files gives you the smallest final document. Name your files clearly before selecting (e.g. "01-cover.pdf", "02-invoice.pdf") so the numbered list is easy to verify at a glance. And for very large merges, close other heavy browser tabs first — all processing happens in memory, and freeing it up keeps things fast.

Common mistakes to avoid

The biggest mistake is selecting files in the wrong order — there's no drag-to-reorder step in this version, so if the numbered list looks wrong, clear the selection and re-select in the right order. Another common trap: password-protected PDFs can't be opened by the browser engine, so remove the password in your PDF reader first. Finally, don't merge first and ask questions later on huge files — merging hundreds of heavy scanned pages can take a minute or two on a slow device, and that's normal; just let it finish.
