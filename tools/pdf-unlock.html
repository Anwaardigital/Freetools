PDF Unlock

Remove the password from a protected PDF you own, and download the unlocked file.

How to use

  1. Select the locked PDF file.
  2. Enter the password you know.
  3. Click “Unlock PDF”.
  4. Download the unlocked file.

FAQ

Is it really free?

Yes — every tool on this site is 100% free with no limits, no signup and no watermarks.

Is my data private?

Absolutely. All processing happens locally in your browser. Your files are never uploaded to any server.

I forgot the password — can this tool guess it?

No. This tool removes a password you already know. It cannot crack or guess a forgotten password.

Is it legal to unlock a PDF?

Only unlock files you own or have permission to unlock — your own documents, or files the owner allowed you to open. Do not unlock other people’s protected files.

Complete Guide to Unlocking PDFs

PDF passwords are useful until you need the file yourself and the password prompt appears for the tenth time. If you know the password, unlocking is simple: this tool opens the file with your password and saves a copy without it. That copy opens anywhere, prints, and can be merged or split like any normal PDF. The tool cannot guess a password you forgot, and it should only be used on files you own or have permission to open. Keep the unlocked copy safe — without the password, anyone who gets the file can open it.
