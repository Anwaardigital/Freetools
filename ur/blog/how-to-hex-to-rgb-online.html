آن لائن مفت HEX سے RGB کیسے تبدیل کریں (2026 گائیڈ)

آپ کا ڈیزائنر آپ کو #3B82F6 دیتا ہے۔ آپ کا CSS فریم ورک rgb(59, 130, 246) چاہتا ہے۔ آپ کا ڈیزائن ٹول ایک فارمیٹ قبول کرتا ہے لیکن جو کوڈ آپ کو ورثے میں ملا ہے وہ دوسرا استعمال کرتا ہے۔ HEX اور RGB کے درمیان ہاتھ سے تبدیل کرنے کا مطلب ہیکساڈیسیمل ریاضی ہے — ممکن، لیکن سست اور غلطی کا شکار۔ یہ گائیڈ بتاتی ہے کہ دونوں فارمیٹس دراصل کیا ہیں، ہر ایک کب استعمال کریں، اور ہمارے مفت HEX to RGB کنورٹر سے فوری طور پر کیسے تبدیل کریں۔

مفت کنورٹر کیا کرتا ہے

HEX to RGB کنورٹر کلر کوڈز کو دونوں سمتوں میں ترجمہ کرتا ہے: HEX کوڈ پیسٹ کریں تو اس کی RGB ویلیوز ملتی ہیں، یا RGB نمبر درج کریں تو HEX کوڈ ملتا ہے۔ تبدیلی فوری اور درست ہے — کوئی راؤنڈنگ نہیں، کوئی اندازہ نہیں — اور یہ بغیر رجسٹریشن مکمل طور پر آپ کے براؤزر میں چلتا ہے۔

HEX اور RGB کی وضاحت (صحیح طریقے سے، ایک بار)

اسکرین پر ہر رنگ تین روشنیوں سے بنتا ہے: سرخ، سبز اور نیلا۔ دونوں فارمیٹس صرف یہ بیان کرتے ہیں کہ ہر روشنی کتنی روشن ہے۔ HEX تین روشنائی کی سطحوں کو # کے بعد ہیکساڈیسیمل (بیس 16) جوڑوں کے طور پر لکھتا ہے۔ #3B82F6 میں، 3B سرخ کی سطح ہے، 82 سبز کی، F6 نیلے کی۔ ہر جوڑا 00 (بند) سے FF (مکمل) تک ہوتا ہے۔ RGB وہی تین سطحیں 0 سے 255 تک اعشاری نمبروں کے طور پر لکھتا ہے: rgb(59, 130, 246)۔ ہیکس میں 3B اعشاری میں 59 کے برابر ہے — ایک ہی رنگ، مختلف علامت۔ ہر چینل میں 256 ممکنہ سطحیں ہیں، اس لیے دونوں فارمیٹس مل کر 256 × 256 × 256 = 16,777,216 مختلف رنگ بیان کر سکتے ہیں۔ ان کے درمیان تبدیل کرنا ان تین نمبروں پر خالص ریاضی ہے — جو ٹول آپ کے لیے کرتا ہے۔

مرحلہ وار: کسی بھی سمت میں تبدیل کریں

  1. HEX to RGB کنورٹر کھولیں۔ بغیر رجسٹریشن، کسی بھی جدید براؤزر میں کام کرتا ہے۔
  2. HEX → RGB تبدیل کرنے کے لیے: اپنا HEX کوڈ پیسٹ یا ٹائپ کریں (# کے ساتھ یا بغیر)۔ ٹول فوری طور پر تین RGB نمبر دکھاتا ہے۔
  3. RGB → HEX تبدیل کرنے کے لیے: تین ویلیوز درج کریں (ہر ایک 0 تا 255)۔ ٹول فوری طور پر HEX کوڈ دکھاتا ہے۔
  4. نتیجہ کاپی کریں اور اسے اپنی اسٹائل شیٹ، ڈیزائن ٹول یا کوڈ میں پیسٹ کریں۔

HEX بمقابلہ RGB کب استعمال کریں

  • روزمرہ کے CSS کام کے لیے HEX استعمال کریں — یہ کمپیکٹ ہے، عالمی طور پر سپورٹ ہوتا ہے، اور زیادہ تر ڈویلپرز یہی اٹھاتے ہیں: color: #3B82F6;۔
  • جب شفافیت چاہیے تو RGB استعمال کریں۔ RGBA چوتھا نمبر، الفا، شامل کرتا ہے، 0 (نظر نہ آنے والا) سے 1 (ٹھوس) تک: rgba(59, 130, 246, 0.5) وہی نیلا ہے، آدھی شفافیت پر۔ CSS میں اوورلیز، شیڈوز اور مدھم عناصر بنانے کا یہ معیاری طریقہ ہے۔
  • کوڈ میں رنگوں پر ریاضی کرتے وقت RGB استعمال کریں — ہلکا کرنا، گہرا کرنا، یا ملانا 0 تا 255 نمبروں سے ہیکس جوڑوں سے زیادہ بدیہی ہے۔
  • ڈیزائن ٹولز کے درمیان رنگ کاپی کرتے وقت HEX استعمال کریں — Figma، Photoshop اور زیادہ تر پکرز بطور ڈیفالٹ HEX قبول اور دکھاتے ہیں۔

شارٹ ہینڈ HEX کوڈز: #FFF کا واقعی کیا مطلب ہے

آپ اکثر تین ہندسوں والے HEX کوڈز دیکھیں گے جیسے #FFF (سفید) یا #333 (گہرا سرمئی)۔ یہ صرف شارٹ ہینڈ ہے: ہر ہندسہ دگنا ہو جاتا ہے، اس لیے #FFF کا مطلب #FFFFFF ہے اور #3BF کا مطلب #33BBFF ہے۔ یہ صرف تب کام کرتا ہے جب ہر جوڑا دو ایک جیسے ہندسوں پر مشتمل ہو۔ اگر آپ کنورٹر میں شارٹ ہینڈ کوڈ پیسٹ کریں، تو یہ توسیع سنبھال لیتا ہے — لیکن اصول جاننا قابل قدر ہے تاکہ آپ دوسروں کی اسٹائل شیٹس پڑھ سکیں۔

عام تبدیلی کی غلطیاں

  • # بھول جانا اختیاری ہے: 3B82F6 اور #3B82F6 ایک ہی رنگ ہیں۔ اگر کوئی ٹول آپ کا پیسٹ مسترد کر دے، تو ہیش شامل کرنے یا ہٹانے کی کوشش کریں۔
  • 0 تا 255 سے باہر ویلیوز: RGB چینلز 255 سے زیادہ نہیں ہو سکتے۔ اگر آپ کا ذریعہ کچھ اور کہتا ہے، تو اوپر کچھ غلط ہے — اسے محدود کریں اور دوبارہ چیک کریں۔
  • چینل کی ترتیب ملانا: یہ ہمیشہ سرخ، سبز، نیلا ہوتا ہے۔ دو چینلز بدلنے سے آپ کو بغیر کسی وارننگ کے مکمل طور پر مختلف رنگ ملتا ہے۔
  • یہ فرض کرنا کہ اسکرین رنگ پرنٹ میں ایک جیسے ہوتے ہیں: HEX/RGB اسکرین کی روشنی بیان کرتے ہیں۔ پرنٹ کام کے لیے، رنگوں کو CMYK تبدیلی اور فزیکل پروفنگ چاہیے ہوتی ہے — ایک مختلف عمل۔
  • تبدیل کرنے کے بجائے اندازہ لگانا: "قریب قریب" رنگ ہر کاپی کے ساتھ مزید دور ہوتے جاتے ہیں۔ ہمیشہ درست تبدیل کریں؛ ٹول اسی لیے ہے۔

عملی ورک فلو: برانڈ کلر سے شفاف اوورلے تک

یہ وہ تبدیلی کا کام ہے جس سے ڈویلپرز مسلسل ٹکراتے ہیں: برانڈ کلر #3B82F6 ہے، اور آپ کو موڈل اوورلے کے لیے نیم شفاف ورژن چاہیے۔ HEX to RGB کنورٹر میں #3B82F6 پیسٹ کریں → آپ کو rgb(59, 130, 246) ملتا ہے۔ اپنی CSS میں لکھیں background: rgba(59, 130, 246, 0.5); — ایک ہی رنگ، 50% شفافیت۔ کنٹراسٹ چیکر سے پس منظر کے خلاف اوورلے ٹیکسٹ چیک کریں تاکہ یہ پڑھنے کے قابل رہے۔ تیس سیکنڈ، صفر ریاضی، درست رنگ محفوظ۔

اکثر پوچھے جانے والے سوالات

کیا کنورٹر مفت ہے؟

جی ہاں — دونوں سمتوں میں لامحدود تبدیلیاں، بغیر رجسٹریشن۔

کیا تبدیلی درست ہے یا تقریبی؟

درست۔ HEX اور RGB ایک ہی تین نمبروں کے لیے دو علامتیں ہیں، اس لیے تبدیلی بغیر نقصان کے ہوتی ہے — رنگ بالکل نہیں بدلتا۔

کیا یہ #FFF جیسے 3 ہندسوں والے شارٹ ہینڈ HEX کو سنبھال سکتا ہے؟

شارٹ ہینڈ کوڈز ہر ہندسہ دگنا کر کے پھیلتے ہیں (#FFF → #FFFFFF)۔ کوڈ درج کریں اور کنورٹر آپ کو درست RGB ویلیوز دیتا ہے۔

میں HEX کلر میں شفافیت کیسے شامل کروں؟

پہلے اسے RGB میں تبدیل کریں، پھر RGBA فارم استعمال کریں: rgba(59, 130, 246, 0.5)۔ آخری نمبر 0 سے 1 تک شفافیت ہے۔
