ٹائم اسٹیمپ کنورٹر

Unix ٹائم اسٹیمپ کو پڑھنے کے قابل تاریخوں میں اور اس کے برعکس بدلیں، لاگز اور APIs کی ڈیبگنگ کے لیے۔ مفت۔

Unix ٹائم اسٹیمپ بالکل کیا ہے؟

یہ 1 جنوری 1970 00:00:00 UTC سے گزرے ہوئے سیکنڈز (یا ملی سیکنڈز) کی تعداد ہے — جسے Unix ایپوک کہا جاتا ہے۔ یہ کمپیوٹرز کے تاریخ اور وقت کی اقدار محفوظ کرنے کا معیاری طریقہ ہے، کیونکہ ایک واحد نمبر غیر مبہم اور موازنہ یا ترتیب دینے میں آسان ہے۔

میں کیسے جانوں کہ میرا ٹائم اسٹیمپ سیکنڈز میں ہے یا ملی سیکنڈز میں؟

ہندسے گنیں: 10 ہندسے یعنی سیکنڈز (مثلاً 1761091200)، اور 13 ہندسے یعنی ملی سیکنڈز (مثلاً 1761091200000)۔ یہ ٹول فارمیٹ خودکار طور پر پہچان لیتا ہے، لیکن ضرورت پڑنے پر آپ ہاتھ سے بھی بدل سکتے ہیں۔

2038 کا مسئلہ کیا ہے؟

پرانے 32 بٹ سسٹمز میں، سائنڈ Unix ٹائم اسٹیمپ 19 جنوری 2038 کو اوور فلو ہو جاتے ہیں۔ اور جدید 64 بٹ سسٹمز، ڈیٹا بیسز اور JavaScript 64 بٹ وقت استعمال کرتے ہیں، اس لیے کوئی بھی حقیقی تاریخ یہاں صحیح تبدیل ہو جاتی ہے۔

کیا ٹائم اسٹیمپ لیپ سیکنڈز اور ٹائم زونز کا خیال رکھتے ہیں؟

Unix وقت جان بوجھ کر لیپ سیکنڈز کو نظر انداز کرتا ہے — اس میں ہر دن بالکل 86,400 سیکنڈز کا ہوتا ہے۔ اور ٹائم زونز صرف اس بات پر اثر ڈالتے ہیں کہ ٹائم اسٹیمپ کیسے دکھایا جاتا ہے: ٹائم اسٹیمپ خود دنیا میں کہیں بھی صحیح مقامی وقت دکھاتا ہے، بس صحیح زون منتخب کریں۔

Unix ٹائم اسٹیمپ کی مکمل گائیڈ

ڈویلپر کے طور پر آپ کو تقریباً ہر ٹائم اسٹیمپ جو ملتا ہے — APIs، ڈیٹا بیسز، لاگ فائلز اور JWT ٹوکنز میں — وہ Unix ٹائم اسٹیمپ ہے: ایک عام نمبر جو Unix ایپوک (آدھی رات، 1 جنوری 1970، UTC) سے سیکنڈز گنتا ہے۔ اسے اس لیے چنا گیا کیونکہ دو لمحوں کا موازنہ معمولی مکمل عدد کی ریاضی بن جاتا ہے، بغیر ٹائم زونز یا فارمیٹس پر بحث کے۔

سیکنڈز بمقابلہ ملی سیکنڈز کا جال یہ حقیقت میں ٹائم اسٹیمپ کی پہلی غلطی ہے۔ Date.now() JavaScript میں واپس کرتا ہے ملی سیکنڈز (13 ہندسے)، جبکہ زیادہ تر سرور APIs اور ڈیٹا بیسز استعمال کرتے ہیں سیکنڈز (10 ہندسے)۔ ملی سیکنڈ والی قدر کو سیکنڈز کی توقع رکھنے والی کوڈ میں پیسٹ کریں اور آپ سال 56,000 تک پہنچ جائیں گے۔ اور یہ کنورٹر ہندسوں کی تعداد خودکار طور پر پہچان لیتا ہے تاکہ آپ ہمیشہ جان سکیں کہ آپ کے پاس کون سا ہے۔

روزمرہ استعمال

  • لاگز کی ڈیبگنگ: سرور لاگز اکثر خام ایپوک اقدار پرنٹ کرتے ہیں — انہیں بدلیں تاکہ بالکل دیکھ سکیں کہ آپ کے ٹائم زون میں کچھ کب ہوا۔
  • API کام: REST APIs واپس کرتی ہیں created_at ایپوک سیکنڈز کے طور پر؛ ٹوکن ختم ہونے یا کیش کی مدت چیک کرنے کے لیے بدلیں۔
  • ڈیٹا بیسز: مائیگریشنز چلانے سے پہلے تصدیق کریں کہ محفوظ شدہ مکمل عدد والی تاریخ کی قدر واقعی کیا ظاہر کرتی ہے۔
  • شیڈولنگ: cron ٹاسکس، یاد دہانیوں یا الٹی گنتی ٹائمرز کے لیے مستپہلے کی تاریخ کو ٹائم اسٹیمپ میں بدلیں۔

کوڈ میں تبدیلی

JavaScript میں: new Date(1761091200 * 1000) (سیکنڈز کو 1000 سے ضرب دیں)۔ اور Python میں: datetime.fromtimestamp(1761091200, tz=timezone.utc)۔ اور PostgreSQL میں: to_timestamp(1761091200)۔ اور دوسری سمت میں: Math.floor(Date.now() / 1000) JS میں، یا int(datetime.now(timezone.utc).timestamp()) Python میں۔

بہترین طریقہ: ٹائم اسٹیمپ ہمیشہ UTC میں محفوظ کریں اور صرف دکھانے کے لیے مقامی وقت میں بدلیں — اور یہی بالکل وہ ہے جو یہ ٹول کرتا ہے جب آپ ٹائم زون منتخب کرتے ہیں۔ اور یہ ایک عادت ٹائم زون کی غلطیوں کی پوری قسم ختم کر دیتی ہے، بشمول ڈے لائٹ سیونگ کی حیرانیاں۔

منفی ٹائم اسٹیمپ اور دور کی تاریخیں

ٹائم اسٹیمپ صرف 1970 کے بعد کی تاریخوں تک محدود نہیں ہیں۔ منفی اقدار ان لمحوں کو ظاہر کرتی ہیں پہلے ایپوک سے — مثلاً، -86400 یعنی 31 دسمبر 1969۔ مورخین اور آرکائیوسٹ 1970 سے پہلے کے ریکارڈز کے لیے منفی ٹائم اسٹیمپ استعمال کرتے ہیں، اور کنورٹر ان سے صحیح نمٹتا ہے۔ اور دور کی تاریخیں بھی کام کرتی ہیں: 64 بٹ ٹائم اسٹیمپ سینکڑوں ملین سالوں تک درست رہتے ہیں، کسی بھی عملی ضرورت سے کہیں آگے۔

حقیقت میں عام ٹائم اسٹیمپ فارمیٹس

  • ISO 8601 اسٹرنگز ("2026-10-22T07:00:00Z") — پڑھنے کے قابل، ترتیب دینے کے قابل اور غیر مبہم۔ APIs کے لیے ترجیحی۔
  • ایپوک سیکنڈز (1761091200) — کمپیکٹ؛ Unix سسٹمز اور PHP میں معیاری (time()) اور زیادہ تر ڈیٹا بیسز میں۔
  • ایپوک ملی سیکنڈز (1761091200000) — JavaScript کی اصل فارمیٹ بذریعہ Date.now().
  • RFC 2822 ("Thu, 22 Oct 2026 07:00:00 GMT") — ای میل اور HTTP ہیڈرز میں استعمال ہوتا ہے۔

جب آپ کو ٹائم اسٹیمپ ملے اور آپ کو اس کے فارمیٹ کا یقین نہ ہو تو اسے پہلے یہاں پیسٹ کریں — خودکار پہچان آپ کو ایک لائن کوڈ لکھنے سے پہلے بتا دے گی کہ آپ سیکنڈز دیکھ رہے ہیں یا ملی سیکنڈز۔
