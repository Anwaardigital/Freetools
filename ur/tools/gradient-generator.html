گریڈینٹ جنریٹر

لائیو پری ویو اور کاپی کرنے کے قابل کوڈ کے ساتھ CSS گریڈینٹ ڈیزائن کریں۔ مفت۔

استعمال کا طریقہ

  1. کلر پکرز سے اپنے کلرز منتخب کریں — دو کلرز سے شروع کریں، یا امیر تر ملاوٹ کے لیے مزید کلر اسٹاپس شامل کریں۔
  2. سمتی ملاوٹ کے لیے لینیئر یا مرکزی نقطے سے پھیلنے والی چمک کے لیے ریڈیل منتخب کریں۔
  3. زاویہ (لینیئر کے لیے) باریک کریں اور کلر اسٹاپ پوزیشنز کھینچیں تاکہ کنٹرول کریں کہ ہر کلر کہاں عروج پر ہو۔
  4. بنایا گیا CSS اسنیپٹ کاپی کریں اور اپنی اسٹائل شیٹ میں پیسٹ کریں — یہ ہر جدید براؤزر میں کام کرتا ہے۔

عام سوالات

کیا یہ واقعی مفت ہے؟

کیا میرا ڈیٹا نجی ہے؟

یقیناً۔ تمام پروسیسنگ آپ کے براؤزر میں مقامی طور پر ہوتی ہے۔ آپ کی فائلیں کبھی کسی سرور پر اپ لوڈ نہیں ہوتیں۔

ٹول کون سا CSS کوڈ بناتا ہے؟

معیاری اعلان جیسے background: linear-gradient(135deg, #667eea 0%, #764ba2 100%)۔ ساخت خالص جدید CSS ہے — کسی وینڈر پریفکس کی ضرورت نہیں — اور یہ background-image ویلیو کے طور پر بھی کام کرتا ہے جسے آپ دیگر بیک گراؤنڈز کے ساتھ رکھ سکتے ہیں۔

کیا میں دو سے زیادہ کلرز استعمال کر سکتا ہوں؟

جی ہاں۔ کثیر رنگی گریڈینٹس بنانے کے لیے اضافی کلر اسٹاپس شامل کریں — غروب آفتاب یا سمندر کی گہرائی یا قوس قزح ایفیکٹس۔ ہر اسٹاپ کا اپنا کلر اور پوزیشن فیصد ہوتا ہے، جو ملاوٹ پر مکمل کنٹرول دیتا ہے۔

لینیئر اور ریڈیل گریڈینٹس میں کیا فرق ہے؟

لینیئر گریڈینٹس آپ کے منتخب زاویے پر سیدھی لائن پر کلرز ملاتے ہیں (0° = نیچے سے اوپر، 90° = بائیں سے دائیں)۔ ریڈیل گریڈینٹس مرکزی نقطے سے دائرے یا بیضوی شکل میں باہر کی طرف ملتے ہیں — چمک، ارد گرد کے سائے اور روشنی کے ایفیکٹس کے لیے بہترین۔

کیا گریڈینٹ ہر براؤزر میں ایک جیسا نظر آئے گا؟

جی ہاں۔ معیاری گریڈینٹ ساخت Chrome، Firefox، Safari اور Edge میں یکساں سپورٹ ہوتی ہے۔ ڈسپلے کیلیبریشن کی وجہ سے کلرز اسکرینوں کے درمیان ہلکے سے مختلف ہو سکتے ہیں، لیکن CSS خود مستقل رینڈر ہوتی ہے۔

گریڈینٹ جنریٹر — مکمل گائیڈ

فلیٹ کلرز محفوظ ہیں؛ گریڈینٹس یادگار ہیں۔ مشہور ایپ آئیکنز سے لے کر ایوارڈ یافتہ سائٹس تک، نرم کلر ملاوٹیں جدید ڈیجیٹل ڈیزائن کی پہچان ہیں۔ یہ گریڈینٹ جنریٹر آپ کو لینیئر اور ریڈیل گریڈینٹس بصری طور پر بنانے دیتا ہے اور صاف، کاپی کے لیے تیار CSS ایکسپورٹ کرتا ہے — ڈیزائن سافٹ ویئر کی ضرورت نہیں۔

کلر تھیوری کا فوری تعارف

گریڈینٹس ان کلرز کے ساتھ بہترین کام کرتے ہیں جن کا آپس میں تعلق ہو۔ ملتے جلتے کلرز (کلر وہیل پر پڑوسی، جیسے نیلے سے جامنی) آسانی سے ملتے ہیں اور پرسکون لگتے ہیں۔ مخالف کلرز (ضد، جیسے نارنجی سے نیلا) متحرک توانائی بناتے ہیں لیکن درمیان میں گدلا ہو سکتے ہیں — منتقلی کنٹرول کرنے کے لیے درمیانی اسٹاپ شامل کریں۔ ٹیکسٹ اوورلیز کے لیے گریڈینٹس اتنے ہلکے اور گہرے رکھیں کہ سفید ٹیکسٹ پڑھنے کے قابل رہے۔

گریڈینٹ کہاں چمکتے ہیں

ہیرو سیکشنز: پوری چوڑائی کا گریڈینٹ بیک گراؤنڈ لینڈنگ پیج کو فوری اٹھاتا ہے۔ بٹن اور کال ٹو ایکشن: گریڈینٹ بٹن چیخے بغیر آنکھ کھینچتے ہیں۔ امیج اوورلیز: اوپر کی طرف مدھم ہوتا گہرا گریڈینٹ کسی بھی امیج پر سفید ہیڈ لائن ٹیکسٹ پڑھنے کے قابل بناتا ہے۔ کارڈز اور ڈیوائیڈرز: باریک گریڈینٹ رولز اور بارڈرز نفاست شامل کرتے ہیں۔ ڈارک موڈ: ہلکے گریڈینٹس فلیٹ ڈارک سطحوں کو بے جان لگنے سے روکتے ہیں۔

پروفیشنل تکنیکیں

سخت اسٹاپس (ایک ہی فیصد پر دو اسٹاپس) نرم ملاوٹوں کے بجائے دھاری دار یا دو رنگی تیز ایفیکٹس کے لیے استعمال کریں۔ گہرائی کے لیے بیک گراؤنڈ امیج پر نیم شفاف گریڈینٹ کی تہہ لگائیں۔ اور زندہ، سانس لیتے انٹرفیسز کے لیے بیک گراؤنڈ پوزیشن ٹرانزیشنز سے گریڈینٹس کو ہلکا سا متحرک کریں — لیکن حرکت نرم رکھیں، ویسٹیبلر حساسیت والے صارفین کا احترام کرتے ہوئے۔ ہمیشہ کنٹراسٹ ریشو چیک کریں: آرائشی گریڈینٹس ٹھیک ہیں، لیکن گریڈینٹ پر بیٹھا ٹیکسٹ پھر بھی رسائی معیارات پر پورا اترنا چاہیے۔

پرفارمنس اور بہترین طریقے

CSS گریڈینٹس ریزولوشن سے آزاد ہیں اور عام طور پر بیک گراؤنڈ امیجز سے ہلکے ہوتے ہیں — پیج اسپیڈ کے لیے بڑا فائدہ۔ جہاں ممکن ہو گریڈینٹس کے لیے PNG فائلوں پر CSS کو ترجیح دیں۔ اور جب وہی گریڈینٹ کئی جگہوں پر چاہیے، تو اسے کسٹم CSS پراپرٹی (--brand-gradient) کے طور پر محفوظ کریں تاکہ مستقبل میں برانڈ تبدیلی کا مطلب صرف ایک لائن میں ترمیم ہو۔
