تقسيم PDF

How to use

  1. Click the drop zone and select the PDF you want to split — or drag and drop it. The file name and size appear below so you can confirm it's the right one.
  2. In the "Pages to extract" box, type the pages you want using this format: 1-3, 5, 7-9 (page numbers and ranges, separated by commas).
  3. Click "Split / Extract Pages" — the tool copies exactly those pages into a brand-new PDF, entirely in your browser.
  4. Your new file downloads automatically as split.pdf. The original PDF is left untouched.

FAQ

Is it really free?

Yes — every tool on this site is 100% free with no limits, no signup and no watermarks.

Is my data private?

Absolutely. All processing happens locally in your browser. Your files are never uploaded to any server.

How do I write the page selection?

List pages as numbers and ranges separated by commas — for example 1-3, 5, 7-9 extracts pages 1, 2, 3, 5, 7, 8 and 9. A range uses a dash (1-3 means pages 1 through 3), and page numbers start at 1. If you enter something invalid, the tool tells you how many pages the PDF actually has so you can fix your selection.

Can I extract pages in a custom order?

Yes — the output keeps the pages in the order you list them. Typing 10, 1-3 produces a PDF starting with page 10 followed by pages 1–3. Duplicate page numbers are removed automatically, and invalid pages are skipped.

Does splitting remove pages from my original PDF?

No. Your original file is never modified — splitting copies the pages you selected into a brand-new PDF. The source document stays exactly as it was, so you can extract as many different page sets as you like from the same file.

Is there a limit on how many pages I can extract?

No — extract a single page or hundreds of pages in one go. The only practical constraint is your device's memory, since all processing happens locally in your browser.

How PDF Splitting Works (and When to Use It)

A PDF is a collection of page objects, each self-contained with its own text, images and resources. Splitting doesn't "cut" anything out of your file — instead, the tool loads your PDF with the open-source pdf-lib engine, copies the page objects you requested into a brand-new document, and rebuilds a valid file around them. The extracted pages are identical copies: same fonts, same images, same layout, same selectable text. Your original file is never opened for writing, so it stays completely untouched no matter how many times you split it.

The whole operation runs in your browser. The PDF engine is fetched from a CDN once (that first load needs an internet connection); after that, splitting works fully offline, and no part of your document ever leaves your device — which matters a lot when you're extracting pages from contracts, bank statements or medical records.

Best use cases

Splitting shines whenever you need a slice of a long document. Typical examples: pulling the pages of one month's statement out of a year-long bank download; extracting a single chapter from an e-book for study; separating one invoice or receipt from a bulk-scanned file; grabbing just the signed signature page of a contract; or carving the visa-application pages out of a bulky travel itinerary. It's also the first step in reorganizing a document: extract the pages you want, then use the PDF Merger to reassemble them in a new order — for example, split, then merge, to reorder a PDF without any extra software.

Tips for the best results

Before typing your selection, quickly scroll through the PDF in any reader and note the exact page numbers you need — the tool counts from page 1, which is the very first page of the file (not the printed page number, which can differ). Use ranges for consecutive pages (5-12 is cleaner than 5, 6, 7, 8, 9, 10, 11, 12) and commas to combine ranges and single pages. If you're unsure of the total, just enter a guess — the tool tells you the real page count when something doesn't match. For big jobs, extract in one selection rather than many small ones; one output file is easier to manage than ten.

Common mistakes to avoid

The classic error is off-by-one page counting: the PDF's internal page 1 is the file's first page, which may differ from the printed footer numbers (a document with a cover and table of contents often starts its "page 1" on the file's third or fourth page). When in doubt, open the file and count from the beginning. Another mistake: trying to split password-protected PDFs — the browser engine can't open them, so remove the password in your PDF reader first. Finally, don't confuse splitting with deleting: if you want to remove pages, extract everything except those pages (e.g. from a 20-page file, extract 1-4, 6-20 to drop page 5).
