البحث عن عنوان IP

ابحث عن أي عنوان IP أو نطاق لعرض مدينته وبلده ومزود الخدمة ومنطقته الزمنية. مجاني.

How to use

  1. Your own public IP address is detected and looked up automatically when the page loads.
  2. To check a different address, type or paste any IPv4 or IPv6 address into the input box.
  3. Click the Lookup button to fetch geolocation and network details for that address.
  4. Review the results: country, city, ISP, timezone and network information displayed below.

FAQ

Is it really free?

Yes — every tool on this site is 100% free with no limits, no signup and no watermarks.

Is the location exact?

No. IP geolocation shows the approximate location of your internet provider's server — usually correct to the city, sometimes only the region.

How accurate is the location shown?

Country-level data is very accurate (99%+). City-level accuracy varies — typically correct within 25–50 km in urban areas, but it shows the ISP's registered location, not your GPS position. Mobile and VPN connections are often geolocated to a distant city.

Why does it show a different city than where I am?

IP geolocation reflects where your internet provider routes your traffic, not your physical location. VPNs, corporate networks, and mobile carriers commonly exit through hubs in other cities. This is normal and doesn't mean anything is wrong.

What is the difference between IPv4 and IPv6?

IPv4 addresses look like 192.0.2.1 (four number groups) — the classic format, now largely exhausted. IPv6 addresses look like 2001:db8::1 (eight hexadecimal groups) — the modern replacement with vastly more addresses. The tool handles both formats.

Can someone find my exact address from my IP?

No. IP geolocation cannot reveal a street address or precise location — only an approximate area based on ISP records. Your exact address is not encoded in your IP address, and this tool only displays what public geolocation databases contain.

IP Lookup — Complete Guide

Every device on the internet has an IP address — the return address that lets data find its way back to you. The IP Lookup tool reveals what the public internet knows about any address: its approximate location, internet provider, timezone and network details. Note that unlike most tools on this site, lookups query a public geolocation API, since this data can't be computed locally.

How it works

When you run a lookup, the tool sends the IP address to a geolocation database service, which matches it against records of how address blocks are allocated to ISPs and regions worldwide. The database returns the country, region, city, latitude/longitude, ISP name, timezone and connection type. Your own IP is detected automatically via the same kind of service every website uses to see your public address.

Understanding your results

  • IP address: your public address as the internet sees it. (Your private home-network addresses like 192.168.x.x are not publicly visible.)
  • Location: the ISP's registered location for that address block — approximate, not GPS-precise.
  • ISP / Organization: the company providing the connection — useful for identifying whether an address belongs to a hosting provider, VPN service or residential ISP.
  • Timezone: derived from the location; handy for scheduling across regions.
  • ASN: the Autonomous System Number identifying the network operator — the same identifier network engineers use.

Common use cases

Checking your VPN: confirm your VPN is working by verifying the lookup shows the VPN server's location, not yours. Debugging geo-issues: if a website shows the wrong country or currency, an IP lookup reveals what location the site thinks you're in. Email header analysis: look up sender IPs from suspicious emails to see if the claimed origin matches reality. Developers: test geolocation features by checking addresses from different regions.

Privacy notes

Websites log your IP on every visit — that's how this lookup works in reverse. If the location feels too revealing, a reputable VPN masks your real address. Also note: because this tool queries an external API, the IP you look up is sent to that geolocation service (standard for any IP lookup tool). Your other data and files never leave your browser.
