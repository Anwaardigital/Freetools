كيفية تنسيق ملفات JSON والتحقق منها عبر الإنترنت مجانًا (دليل 2026)

JSON (ترميز كائنات جافا سكريبت) هو اللغة التي تتحدث بها واجهات برمجة التطبيقات. سواء كنت تبني موقعًا، أو تضبط إعدادات تطبيق، أو تصحّح أخطاء خادم، فستواجه مشكلتين باستمرار: ملف JSON في سطر واحد لا يُقرأ، وملف JSON يرفض التحليل بسبب فاصلة واحدة في غير موضعها. يوضح لك هذا الدليل كيفية تنسيق ملفات JSON وتجميلها وتصغيرها والتحقق منها عبر الإنترنت مجانًا — خطوة بخطوة، مع أمثلة تصحيح أخطاء حقيقية.

لماذا يهم تنسيق JSON

تنقل واجهات برمجة التطبيقات والخوادم ملفات JSON في أكثر صورها إيجازًا — كل شيء في سطر واحد، دون مسافات. هذا فعّال للآلات لكنه مرهق للبشر. التنسيق (ويسمى أيضًا "التجميل" أو "الطباعة الجميلة") يضيف المسافات البادئة وفواصل الأسطر حتى تتمكن فعلًا من قراءة البنية. أما التصغير فيفعل العكس: يزيل كل ذلك مجددًا للاستخدام الإنتاجي.

أما التحقق فيجيب عن سؤال مختلف: هل ملف JSON هذا سليم أصلًا؟ فاصلة زائدة واحدة، أو علامة اقتباس مفقودة، أو تعليق لُصق بالخطأ، كلها كافية لأن يرفض المحلّل المستند كله. يخبرك أداة التحقق بالخطأ تحديدًا بدل أن تظل تخمّن.

خطوة بخطوة: تنسيق JSON بأداتنا المجانية

تعمل أداة تنسيق JSON الخاصة بنا بالكامل في متصفحك — الصق أي شيء، حتى ملفات JSON التي تحتوي على مفاتيح واجهات برمجة التطبيقات، فلن تغادر جهازك أبدًا. إليك طريقة استخدامها:

  1. افتح أداة تنسيق JSON. سترى مربعين: مربع إدخال ("الصق JSON هنا...") ومربع نتائج.
  2. الصق ملف JSON في مربع الإدخال. يمكن أن يكون مصغّرًا، أو منسّقًا جزئيًا، أو فوضويًا — لا يهم.
  3. انقر على "تنسيق / تجميل". يعرض مربع النتائج البيانات نفسها بمسافة بادئة من مسافتين، وقيمة واحدة في كل سطر.
  4. انقر على "نسخ" لنسخ النتيجة المنسّقة إلى الحافظة.

يغطي زران آخران المهمتين الأخريين: "تصغير" يضغط JSON في سطر واحد للاستخدام الإنتاجي، و"تحقق" يفحص سلامة البناء ويعرض إما "JSON سليم ✓" أو الخطأ تحديدًا.

مثال عملي: تصحيح أخطاء استجابة واجهة برمجة تطبيقات

تخيّل أنك تستدعي واجهة طقس وتحصل على هذا السطر الواحد:

{"city":"Lahore","temp":31,"desc":"Sunny","alerts":[{"type":"heat","level":2}]}

الصقه وانقر على "تنسيق / تجميل". سترى الآن:

{
  "city": "Lahore",
  "temp": 31,
  "desc": "Sunny",
  "alerts": [
    {
      "type": "heat",
      "level": 2
    }
  ]
}

أصبحت البنية واضحة فورًا: حقل alerts مصفوفة من الكائنات. إذا كان برنامجك يتعطل أثناء محاولة قراءة alerts.type، فإن العرض المنسّق يكشف الخطأ — أنت بحاجة إلى alerts[0].type.

مثال عملي: العثور على خطأ في البناء

أنت تحرر ملف إعدادات والتطبيق لا يعمل. تلصقه وتنقر على "تحقق":

JSON غير سليم: اسم خاصية متوقع بين علامتي اقتباس مزدوجتين في JSON عند الموضع 42

هكذا تخبرك الأداة أن اسم خاصية ينقصه علامتا الاقتباس — خطأ شائع عند تحرير الإعدادات يدويًا. أصلح علامات الاقتباس، وتحقق مجددًا، وستحصل على "JSON سليم ✓". هذا أفضل من التحديق في جدار من الأقواس عشرين دقيقة.

حالات استخدام حقيقية

  • تصحيح أخطاء واجهات برمجة التطبيقات: الصق الاستجابات الخام من علامة تبويب الشبكة في متصفحك، وجمّلها، وافحص بنيتها قبل كتابة كود التحليل.
  • ملفات الإعدادات: package.json وtsconfig.json وإعدادات VS Code — تحقق منها بعد كل تعديل يدوي لالتقاط الأخطاء المطبعية فورًا.
  • إعداد حمولات الاختبار: اكتب حمولة بتنسيق جميل، ثم صغّرها في سطر واحد لأوامر curl أو عملاء HTTP.
  • تنظيف البيانات للتخزين: صغّر مستندات JSON الكبيرة قبل حفظها في قاعدة بيانات أو في localStorage لتقليل حجمها.
  • التدريس والتوثيق: JSON المجمّل أسهل بكثير للشرح في درس تعليمي أو تعليق مراجعة كود.

تنسيق أم تصغير: أيهما أحتاج؟

  • استخدم تنسيق / تجميل عندما يحتاج إنسان إلى قراءة JSON أو تحريره: تصحيح الأخطاء، كتابة الإعدادات، التوثيق، مراجعات الكود.
  • استخدم التصغير عندما ستستهلك آلةٌ ملف JSON ويهمّ الحجم: حمولات واجهات برمجة التطبيقات، الملفات المقدَّمة للمتصفحات، البيانات المضمّنة.
  • استخدم التحقق أولًا كلما كان شيء ما "يُفترض أن يعمل لكنه لا يعمل" — فالبناء غير السليم هو أكثر أخطاء JSON شيوعًا.

أخطاء JSON شائعة يكشفها المدقق

  • الفواصل الزائدة: {"a": 1,} — سليمة في جافا سكريبت، غير قانونية في JSON.
  • علامات الاقتباس المفردة: {'a': 1} — يتطلب JSON علامات اقتباس مزدوجة.
  • التعليقات: // note — تسمح بها بعض ملفات الإعدادات أحيانًا، لكن JSON الصارم لا يسمح بها أبدًا.
  • المفاتيح غير المقتبسة: {a: 1} — يجب أن تكون المفاتيح سلاسل نصية مقتبسة.
  • الفواصل المفقودة بين الخصائص أو عناصر المصفوفة.

ملاحظة خصوصية: آمن للصق الأسرار

ترسل كثير من أدوات JSON عبر الإنترنت النص الذي تلصقه إلى خادم — وهذا محفوف بالمخاطر عندما يحتوي JSON على مفاتيح واجهات برمجة التطبيقات أو رموز أو بيانات عملاء. تحلّل أداتنا كل شيء محليًا في متصفحك باستخدام JSON.parse؛ فلا يُنقل شيء. يمكنك التحقق بنفسك: الصق JSON مع فصل الشبكة وستظل الأداة تعمل.

الأسئلة الشائعة

هل يوجد حد للحجم؟

تتعامل الأداة مع الملفات المعتادة — استجابات واجهات برمجة التطبيقات والإعدادات وملفات البيانات — دون مشكلة. أما الملفات الضخمة جدًا (عشرات الميغابايت) فقد تُبطئ أي أداة تنسيق تعمل في المتصفح، وفي هذه الحالة تكون أداة سطح المكتب أفضل.

هل يغيّر التنسيق بياناتي؟

لا. التنسيق يغيّر المسافات البيضاء فقط. تظل القيم المحلّلة وترتيب المفاتيح والأرقام كما هي تمامًا — يمكنك تصغير JSON المنسّق والحصول على مستند مكافئ.

ما الفرق بين JSON وكائنات جافا سكريبت؟

JSON تنسيق بيانات صارم: علامات اقتباس مزدوجة فقط، دون تعليقات، ودون دوال، ودون فواصل زائدة. أما كائنات جافا سكريبت الحرفية فأكثر تساهلًا. الكود الذي يعمل ككائن جافا سكريبت قد يفشل كملف JSON — وهذا بالضبط ما وُجد المدقق من أجله.
