HEX and RGB explained (properly, once)

Every color on a screen is made of three lights: red, green, and blue. Both formats just describe how bright each light is.

  • HEX writes the three brightness levels as hexadecimal (base-16) pairs after a #. In #3B82F6, 3B is the red level, 82 the green, F6 the blue. Each pair ranges from 00 (off) to FF (full).
  • RGB writes the same three levels as decimal numbers from 0 to 255: rgb(59, 130, 246). 3B in hex equals 59 in decimal — same color, different notation.

There are 256 possible levels per channel, so the two formats together can express 256 × 256 × 256 = 16,777,216 distinct colors. Converting between them is pure arithmetic on those three numbers — which is exactly what the tool does for you.

When to use HEX vs. RGB

  • Use HEX for everyday CSS work — it's compact, universally supported, and what most developers reach for: color: #3B82F6;.
  • Use RGB when you need transparency. RGBA adds a fourth number, alpha, from 0 (invisible) to 1 (solid): rgba(59, 130, 246, 0.5) is the same blue at half opacity. This is the standard way to make overlays, shadows, and faded elements in CSS.
  • Use RGB when doing math on colors in code — lightening, darkening, or blending is more intuitive with 0–255 numbers than with hex pairs.
  • Use HEX when copying colors between design tools — Figma, Photoshop, and most pickers accept and display HEX by default.

Shorthand HEX codes: what #FFF really means

You'll often see three-digit HEX codes like #FFF (white) or #333 (dark gray). This is just shorthand: each digit is doubled, so #FFF means #FFFFFF and #3BF means #33BBFF. It only works when each pair consists of two identical digits. If you paste a shorthand code into the converter, it handles the expansion — but it's worth knowing the rule so you can read other people's stylesheets.

Common conversion mistakes

  • Forgetting the # is optional: 3B82F6 and #3B82F6 are the same color. If a tool rejects your paste, try adding or removing the hash.
  • Values outside 0–255: RGB channels can't exceed 255. If your source says otherwise, something's wrong upstream — clamp it and double-check.
  • Mixing up the channel order: it's always red, green, blue. Swapping two channels gives you a completely different color with no warning.
  • Assuming screen colors print the same: HEX/RGB describe screen light. For print work, colors need CMYK conversion and physical proofing — a different process entirely.
  • Eyeballing instead of converting: "close enough" colors drift further apart with every copy. Always convert exactly; that's what the tool is for.
