HEX vs. RGB: a 30-second explanation

Both formats describe the exact same color; they just write it differently. HEX is a six-digit code (after the #) where each pair of digits represents the red, green, and blue components in hexadecimal — #FF0000 is pure red. RGB writes the same three components as decimal numbers from 0 to 255 — rgb(255, 0, 0) is that same pure red.

Which should you use? For CSS and most web work, HEX is the common default. RGB becomes useful when you need transparency — rgba(59, 130, 246, 0.5) is the same blue at 50% opacity, something HEX can't express on its own. Everyday situations where a color picker saves you

Building a palette from one picked color

One color is rarely enough — here's how to grow it into a full palette:

  1. Pick your base color with the Color Picker and copy its HEX code.
  2. Find its shades: pick darker versions of the same hue for hover states, borders, and depth; pick lighter versions for backgrounds and subtle fills.
  3. Add one accent: generate options with the Random Color Palette tool until you find a color that energizes the base without clashing.
  4. Blend them: preview the base and accent together in the Gradient Generator — if they blend pleasantly, they'll coexist happily in a layout.
  5. Check readability: run your text/background pairs through the Contrast Checker to make sure real users can actually read your content.

Tips for picking colors well

  • Pick on the screen where it will live. Colors shift between phone and desktop displays. If the color is for a mobile app, do your final picking on a phone.
  • Test in context, not in isolation. A swatch that looks perfect alone can feel wrong next to your actual content. Paste the code into a real draft early.
  • Write down the codes. Keep a tiny palette document — even a notes file with five HEX codes — so every future asset matches. "The blue from the homepage" is not a specification; #3B82F6 is.
  • Mind the background: the same color looks different on white versus dark backgrounds (simultaneous contrast). Always judge a color against the background it will sit on.
  • Limit your palette. Three to five colors is plenty for most projects. More colors usually means less cohesion, not more creativity.

What's the difference between HEX and RGB?

They describe the same color in different notation. HEX (#3B82F6) is compact and standard in CSS; RGB (rgb(59, 130, 246)) lists the red/green/blue components as numbers 0–255 and supports an alpha channel for transparency via RGBA.

Can I convert a HEX code I already have into RGB?

Will the color look the same everywhere?

Very close, but not pixel-identical: every screen is calibrated slightly differently. For critical brand work, verify on the actual devices your audience uses.
