Çevrimiçi Ücretsiz JSON Nasıl Biçimlendirilir ve Doğrulanır (2026 Rehberi)

JSON (JavaScript Object Notation), API'lerin konuştuğu dildir. İster bir web sitesi yapıyor, ister bir uygulama yapılandırıyor, ister bir arka ucu hata ayıklıyor olun, düzenli olarak iki sorunla karşılaşırsınız: okunamayan tek satırlık JSON ve yalnızca yanlış yere konmuş bir virgül yüzünden ayrıştırılmayı reddeden JSON. Bu rehber, çevrimiçi ücretsiz JSON'u nasıl biçimlendireceğinizi, güzelleştireceğinizi, küçülteceğinizi ve doğrulayacağınızı gösteriyor — adım adım, gerçek hata ayıklama örnekleriyle.

JSON Biçimlendirme Neden Önemlidir

API'ler ve sunucular JSON'u en sıkıştırılmış hâliyle aktarır — her şey tek satırda, hiç boşluk yok. Bu makineler için verimlidir ama insanlar için eziyettir. Biçimlendirme ("güzelleştirme" veya "pretty-print" olarak da bilinir), yapıyı gerçekten okuyabilmeniz için girinti ve satır sonları ekler. Buna karşılık küçültme, üretim kullanımı için bunların hepsini geri kaldırır. Doğrulama ise farklı bir soruya yanıt verir: Bu JSON tam olarak geçerli mi? Sondaki bir virgül, eksik bir tırnak veya yanlışlıkla yapıştırılmış bir yorum, ayrıştırıcının belgenin tamamını reddetmesine neden olur. Bir doğrulayıcı, tahmin etmek yerine tam olarak neyin yanlış olduğunu söyler.

Adım Adım: Ücretsiz Aracımızla JSON Biçimlendirin

JSON Biçimlendiricimiz tamamen tarayıcınızda çalışır — API anahtarları içeren JSON bile olsa, yapıştırdığınız hiçbir şey cihazınızdan asla ayrılmaz. Kullanımı şöyledir: JSON Biçimlendiriciyi açın. İki kutu görürsünüz: giriş kutusu ("Paste JSON here...") ve sonuç kutusu. JSON'unuzu giriş kutusuna yapıştırın. Küçültülmüş, kısmen biçimlendirilmiş veya dağınık olabilir — fark etmez. "Format / Beautify" düğmesine tıklayın. Sonuç kutusu aynı veriyi 2 boşluk girintiyle, her değer ayrı satırda gösterir. Biçimlendirilmiş sonucu panonuza kopyalamak için "Copy" düğmesine tıklayın. İki düğme daha diğer işleri kapsar: "Minify", JSON'u üretim için tek satıra sıkıştırır ve "Validate" sözdizimini denetler ve ya "Valid JSON ✓" ya da doğru bir hata raporu verir.

Uygulamalı Örnek: Bir API Yanıtında Hata Ayıklama

Bir hava durumu API'sini çağırdığınızı ve şu tek satırlık yanıtı aldığınızı düşünün: {"city":"Lahore","temp":31,"desc":"Sunny","alerts":[{"type":"heat","level":2}]} Bunu yapıştırın ve "Format / Beautify" düğmesine tıklayın. Şimdi şunu görürsünüz: {   "city": "Lahore",   "temp": 31,   "desc": "Sunny",   "alerts": [     {       "type": "heat",       "level": 2     }   ] } Yapı hemen anlaşılır: alerts alanı, nesnelerden oluşan bir dizidir. Kodunuz alerts.type değerini okumaya çalışırken çöküyorsa, biçimlendirilmiş görünüm hatayı ortaya çıkarır — alerts[0].type değerine ihtiyacınız var.

Uygulamalı Örnek: Bir Sözdizimi Hatası Bulma

Bir yapılandırma dosyasını düzenliyorsunuz ve uygulama başlamıyor. Dosyayı yapıştırıp "Validate" düğmesine tıklıyorsunuz: Invalid JSON: Expected double-quoted property name in JSON at position 42 Araç size özellik adının tırnaklarının eksik olduğunu söylüyor — yapılandırmaları elle düzenlerken sık yapılan bir hata. Tırnakları düzeltin, yeniden doğrulayın ve "Valid JSON ✓" sonucunu alırsınız. Bu, yirmi dakika boyunca bir süslü parantez duvarına bakmaktan iyidir.

Gerçek Kullanım Alanları

  • API'lerde hata ayıklama: Tarayıcınızın ağ sekmesinden ham yanıtları yapıştırın, güzelleştirin ve ayrıştırma kodu yazmadan önce yapıyı inceleyin.
  • Yapılandırma dosyaları: package.json, tsconfig.json, VS Code ayarları — her elle düzenlemeden sonra doğrulayın, böylece yazım hataları hemen yakalanır.
  • Test yükleri hazırlama: Yükü düzgün biçimlendirilmiş olarak yazın, sonra curl komutları veya HTTP istemcileri için tek satıra küçültün.
  • Depolama için veri temizleme: Büyük JSON belgelerini bir veritabanına veya localStorage'a kaydetmeden önce küçültün, böylece boyutları azalır.
  • Öğretme ve belgeleme: Güzelleştirilmiş JSON'u bir eğitimde veya kod incelemesi yorumunda açıklamak çok daha kolaydır.

Biçimlendirme mi Küçültme mi: Hangisine İhtiyacım Var?

Bir insanın JSON'u okuması veya düzenlemesi gerektiğinde Format / Beautify kullanın: hata ayıklama, yapılandırma yazma, belgeleme, kod incelemeleri. Bir makinenin JSON'u kullanacağı ve boyutun önemli olduğu durumlarda Minify kullanın: API yükleri, tarayıcılara sunulan dosyalar, gömülü veriler. Bir şey "çalışması gerekirken çalışmadığında" önce Validate kullanın — yanlış sözdizimi en yaygın JSON hatasıdır.

Doğrulayıcının Yakaladığı Yaygın JSON Hataları

  • Sondaki virgüller: {"a": 1,} — JavaScript'te geçerli, JSON'da geçersiz.
  • Tek tırnaklar: {'a': 1} — JSON'da çift tırnak gerekir.
  • Yorumlar: // note — yapılandırma dosyaları bazen bunlara izin verir, katı JSON asla izin vermez.
  • Tırnaksız anahtarlar: {a: 1} — anahtarlar tırnaklı dizeler olmalıdır.
  • Özellikler veya dizi öğeleri arasında eksik virgüller.

Gizlilik Notu: Sırları Yapıştırmak Güvenlidir

Birçok çevrimiçi JSON aracı, yapıştırdığınız metni bir sunucuya gönderir — JSON API anahtarları, jetonlar veya müşteri verileri içerdiğinde bu risklidir. Bizim biçimlendiricimiz her şeyi tarayıcınızda JSON.parse ile yerel olarak ayrıştırır; hiçbir şey aktarılmaz. Bunu kendiniz de doğrulayabilirsiniz: ağ bağlantınızı kesip JSON yapıştırın, araç yine de çalışır.

Sık Sorulan Sorular

Bir boyut sınırı var mı?

Araç, sıradan dosyaları — API yanıtlarını, yapılandırmaları, veri dosyalarını — sorunsuz işler. Aşırı büyük dosyalar (onlarca megabayt), tarayıcı tabanlı her biçimlendiriciyi yavaşlatabilir; böyle bir durumda masaüstü bir araç daha iyidir.

Biçimlendirme verimi değiştirir mi?

Hayır. Biçimlendirme yalnızca boşlukları değiştirir. Ayrıştırılmış değerler, anahtar sırası ve sayılar tamamen aynı kalır — biçimlendirilmiş JSON'u küçülterek eşdeğer belgeyi geri alabilirsiniz.

JSON ile JavaScript nesneleri arasındaki fark nedir?

JSON katı bir veri biçimidir: yalnızca çift tırnak, yorum yok, işlev yok, sondaki virgül yok. JavaScript nesne değişmezleri daha esnektir. Bir JS nesnesi olarak çalışan kod, JSON olarak başarısız olabilir — doğrulayıcı tam da bu yüzden vardır.
